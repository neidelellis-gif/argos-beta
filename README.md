# ARGOS Beta

ARGOS Beta é uma plataforma de inteligência para investimentos.

## Objetivo

Construir um sistema capaz de:

- coletar dados automaticamente;
- calcular indicadores;
- registrar histórico;
- apoiar decisões de investimento.

## Arquitetura

- ARGOS Data Engine
- ARGOS Core
- ARGOS ID
